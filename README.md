# Wake Up House

Strona menu Wake Up House zbudowana w React i TanStack Start. Projekt jest
połączony z Lovable; zmiany wypchnięte do `main` synchronizują się z edytorem.

## Uruchomienie lokalne

Wymagane: Node.js i npm.

```sh
npm install
npm run dev
```

## Budowanie

```sh
npm run build
npm run preview
```

Zdjęcia dań znajdują się w `public/`, a dane menu w `src/lib/menu.ts`. Koszyk
jest lokalnym podglądem i nie składa zamówień ani nie pobiera płatności.
